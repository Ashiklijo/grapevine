## What did not run

- **Expired proposals.** A testnet proposal takes seven days to expire, so the path that finalizes one is covered by the rule tests and by the contract's tests on near-sdk's mocked runtime (`cargo test -p grapevine`), not by a live run.
- **A failed transfer.** The retry after a transfer fails on the DAO is covered the same way: by the rule tests and the mocked-runtime tests, not by a live run.
- **Mainnet.** Nothing was deployed or signed on mainnet. near.social's own indexer and app are mainnet-only, so posts here are the same `social-kv/1` writes on testnet, read back from FastNEAR's public testnet KV API.
- **Trezu.** Its hosted app is mainnet-only. The proposals use the description format its parser reads, and that was checked by reading its source, not by running it.
- **A real wallet in the browser.** The site is read-only without the demo server. `scripts/try.mjs` is the way in with your own testnet account.
